# محرّكات التعلّم — المعلّم والحلّال والاتساق (2026-08-21)

بوابة تعلّم إبداعية تشرح وتحلّ للطلبة **بمسؤولية**، تحترم النزاهة الأكاديمية وسياسة المقرر، وتعمل بأي لغة.

## 1) المعلّم (Khan-style Tutor) — `POST /api/learn/explain`
`src/server/tutor.ts`
- يشرح أي موضوع بأسلوب خان: **حدس → بناء تدريجي → مثال → أسئلة تحقّق ذاتي → أخطاء شائعة**.
- **بأي لغة** (توجيه صريح للنموذج) — نصّي (ليس فيديو).
- لا يكتب واجب الطالب القابل للتسليم.
- بلا مزوّد AI: سقالة صادقة بلا محتوى مختلق.

## 2) الحلّال (Policy-Gated Solver) — `POST /api/learn/solve`
`src/server/solver.ts` — **يحلّ للطلبة فعلًا، لكن بمسؤولية**:

| الحالة | الوضع |
|---|---|
| مسألة تدريب/مذاكرة (غير مربوطة بواجب) | **حلّ كامل** خطوة بخطوة (أداة تعلّم، ليس للتسليم) |
| واجب مربوط بمقرر **يسمح** بالذكاء الاصطناعي (level ≥ 4، غير محظور) | **حلّ كامل + ختم إفصاح إلزامي** (شفافية للأستاذ) |
| واجب **يمنع** الذكاء الاصطناعي / سياسة منخفضة / غير مؤكّدة | **إرشاد سقراطي** — تلميحات وخطوات دون تسليم الإجابة النهائية |

- القرار نقيّ وحتمي (`decideSolveMode`) ومختبَر.
- كل حلّ يحمل **إفصاحًا**، ويُسجَّل في السجل التدقيقي عند الربط بواجب.
- **لا وضع غش خفي**: لا يُنتج عملًا قابلًا للتسليم حيث تمنعه السياسة، ولا يُخفي مساعدة الذكاء الاصطناعي.
- النزاهة مصونة أصلًا في بقية المنتج: الـAI Faculty يراجع عمل الطالب ولا يكتبه، والأصالة تُثبَت عبر Evidence Capsule + Viva.

## 3) الاتساق (Content-Addressed Cache)
`src/server/learn-cache.ts` + `getLearnCache/setLearnCache` في `db.ts`
- نفس السؤال (الموضوع/المسألة + اللغة + المستوى/الوضع) => **نفس النتيجة بالضبط** + توفير تكلفة.
- **الشرح:** مخزّن بنطاق **المقرر/الجامعة** (tenant) — طلاب نفس المقرر يرون نفس الشرح المتّسق.
- **الحلّ:** يُخزَّن **فقط للمسائل التدريبية** (غير المربوطة بواجب) — تجنّبًا لتطابق حلول التسليمات المُقيَّمة.
- مصدر الاستجابة مُعلَن: `ai` / `cache` / `scaffold`.
